## Screenshot Tips

- Use a resolution of at least 1920x1080 for clarity
- Ensure the browser window is maximized or at a good size
- Make sure all relevant UI elements are visible
- Use PNG format for better quality
- Consider using a screenshot tool like:
  - Windows: Snipping Tool or Win + Shift + S
  - Browser DevTools: F12 > Device Toolbar for consistent sizing
  - Third-party: ShareX, Greenshot, etc.

## After Capturing

Once you've captured all screenshots:
1. Save them in this directory with the exact filenames listed above
2. The README.md will automatically display them
3. Commit the images to your repository
